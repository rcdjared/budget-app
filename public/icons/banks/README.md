# Institution logo assets

Upload official transparent or square PNG logos into this folder. The application requests them from `/icons/banks/<filename>` and automatically shows an initials plus bank/wallet icon fallback until each file is present.

| Institution | Required file |
|---|---|
| AUB | `aub.png` |
| BDO | `bdo.png` |
| Bank of Commerce | `bankofcommerce.png` |
| BPI | `bpi.png` |
| China Bank | `chinabank.png` |
| China Bank Savings | `chinabanksavings.png` |
| CIMB | `cimb.png` |
| Coins.ph | `coinsph.png` |
| DBP | `dbp.png` |
| EastWest Bank | `eastwest.png` |
| GCash | `gcash.png` |
| GoTyme Bank | `gotyme.png` |
| GrabPay | `grabpay.png` |
| LandBank | `landbank.png` |
| MariBank | `maribank.png` |
| Maybank | `maybank.png` |
| Maya | `maya.png` |
| Maya Bank | `mayabank.png` |
| Metrobank | `metrobank.png` |
| PayPal | `paypal.png` |
| PNB | `pnb.png` |
| PSBank | `psbank.png` |
| RCBC | `rcbc.png` |
| SeaBank | `seabank.png` |
| Security Bank | `securitybank.png` |
| ShopeePay | `shopeepay.png` |
| Tonik | `tonik.png` |
| UnionBank | `unionbank.png` |

Cash / Wallet uses the built-in fallback and does not need a logo file.
